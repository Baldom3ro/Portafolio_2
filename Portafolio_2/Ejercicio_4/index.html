Estructura de la Transacción en IndexedDB: 

// 1. Apertura de transacción readwrite
const tx = db.transaction('registros', 'readwrite');
const store = tx.objectStore('registros');

// 2. Operación asíncrona (add / put / delete)
const request = isEdit ? store.put(record) : store.add(record);
request.onsuccess = () => console.log('Transacción completada exitosamente sin red');
